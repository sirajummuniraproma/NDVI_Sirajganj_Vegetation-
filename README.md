# NDVI_Sirajganj_Vegetation-
NDVI Analysis of Sirajganj District (2021)
This project analyzes the Normalized Difference Vegetation Index (NDVI) of Sirajganj District, Bangladesh using Sentinel-2 satellite imagery in Remote Sensing and Geographic Information Systems.
📍 Study Area
Sirajganj District, Bangladesh
🛰️ Data Source
Sentinel-2 Surface Reflectance (COPERNICUS/S2_SR_HARMONIZED)
Boundary Data: FAO GAUL Administrative Boundary Dataset
🛠️ Tools & Platforms
Google Earth Engine (GEE)
JavaScript
Remote Sensing Techniques
📊 Objectives
Calculate NDVI values for 2021
Monitor vegetation conditions
Visualize spatial distribution of vegetation health
